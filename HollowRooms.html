A first-person educational horror game

HollowRooms

You are a detective searching an abandoned building for four missing children. The blind dolls cannot see you—but they hear every mistake. Repair the security station, restore power, solve a birth-year code, and lead everyone outside.

⌨ Desktop controls
WASD move · Mouse look · Shift run · E interact · F flashlight · N notebook · Esc pause
📱 Phone controls
Left joystick move · Swipe right side to look · RUN, E, F, N buttons
Learn by doing
Connect hardware, follow instructions, calculate a code, and plan around sound.
Stay quiet
Glass, creaky boards, running, and alarms attract dolls. Lockers are safe hiding places.
In-game date: October 15, 2026. No real computer commands are required.
Missing children · case file
Walk on ordinary flooring to stay silent. Interact within 1.5 m and with a clear view. You can hide in lockers with E. If caught, only the current station resets; completed stations and their points remain. Use the notebook for letters and child cards.
